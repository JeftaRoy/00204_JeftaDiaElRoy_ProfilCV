# Tugas 1 - Profil Pribadi

Website profil pribadi ala LinkedIn yang menampilkan informasi diri, pendidikan, keahlian, organisasi, pengalaman, dan kontak. Website dibuat menggunakan HTML5 dan Tailwind CSS dengan desain sederhana, dan responsif.

## Live Demo
https://jeftaroy.github.io/00204_JeftaDiaElRoy_ProfilCV/

## Teknologi
- HTML5
- CSS3
- CSS variables
- Flexbox
- Grid
- Tailwind CSS

## Cara Membuka
Buka file `index.html` langsung di browser, atau kunjungi link live di atas.
